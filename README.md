# Projeto Forms – Validação com HTML, CSS e JavaScript  

Este projeto foi desenvolvido como atividade prática na disciplina de **Front-End**, no curso técnico em **Desenvolvimento de Sistemas – SENAI**.
O objetivo foi aplicar conceitos fundamentais de HTML, CSS e JavaScript na criação de um formulário interativo com validação de dados.

## Objetivo do Projeto

Desenvolver um formulário capaz de:

- Coletar nome, idade e nível de experiência do usuário  
- Validar as informações inseridas  
- Exibir mensagens conforme as regras definidas  
- Aplicar estilização com CSS  
- Utilizar JavaScript externo para organizar a lógica
